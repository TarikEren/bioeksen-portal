# Training Studio

Training Studio is a React backoffice authoring application.

## Required capabilities

- create/edit courses and versions
- create/reorder modules and lessons
- add/reorder content blocks
- edit Turkish and English content in the same authoring experience
- preview learner rendering
- save draft
- submit to a selected reviewer
- course-level comments
- block-level comments
- review completion
- approval by an authorized different person
- explicit publication

## Authoring safety

Authors configure supported block types. They do not write arbitrary JavaScript or upload executable course code.

## Accessibility

If drag-and-drop is offered for authoring or learning, provide a non-drag alternative for essential actions where practical.
