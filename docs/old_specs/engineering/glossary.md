# Ubiquitous Language

Use one canonical English term per domain concept.

| Business concept | Canonical code term |
|---|---|
| Ürün | Product |
| Katalog No / CAT No | CatalogNumber |
| Lot No | Lot / lot_number |
| Üretim tarihi | manufacturing_date |
| Kullanım Talimatı | Instructions for Use / IFU |
| Doküman | Document |
| Doküman versiyonu | DocumentVersion |
| Revizyon | revision |
| Geçerlilik | applicability |
| Eğitim | Training |
| Kurs | Course |
| Kurs versiyonu | CourseVersion |
| Modül | Module |
| Ders | Lesson |
| İçerik bloğu | ContentBlock |
| Değerlendirme | Assessment |
| Sertifika | Certificate |
| Kuruluş | Organization |
| Üyelik | OrganizationMembership |
| Onay | Approval |
| Yayınlama | Publication |
| Denetim kaydı | AuditEvent |

Do not alternate between `CatNo`, `Catalogue`, `ReferenceCode`, and `CatalogNumber` for the same concept.

Examples:

- Catalog Number: `BS-GHPV-L-100`
- LOT Number: `B2603091224GHPVV`

The example values do not imply that all future identifiers will share identical lengths or suffix patterns. Only the documented LOT date rule may be semantically parsed.
